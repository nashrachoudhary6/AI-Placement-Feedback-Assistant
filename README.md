🎯 AI Placement Feedback Assistant

📌 Project Overvie
AI Placement Feedback Assistant is an AI-powered application designed to evaluate technical interview answers and help students improve their interview performance. It analyzes responses, assigns scores based on predefined evaluation criteria, and generates personalized feedback with actionable improvement suggestions.

✨ Key Features
AI Question Generation: Generate technical interview questions based on selected job roles.
Custom Questions: Enter your own interview questions for practice.
Answer Analysis: Evaluate answers based on technical correctness, relevance, clarity, and completeness.
Performance Scoring: Receive an AI-generated score out of 10.
Personalized Feedback: Get strengths, areas for improvement, and three specific improvement suggestions.
Sample Improved Answer: Understand how to structure better interview responses.
Evaluation Report: Generate and download detailed interview evaluation reports.
Performance Dashboard: View evaluation scores and the latest interview results.

🛠️ Technology Stack
Python – Core programming language
Streamlit – Interactive web application interface
LangChain – Integration with language models
LangGraph – Workflow orchestration and conditional routing
OpenRouter – AI model access (GPT-OSS-20B)
LangSmith – Workflow monitoring
Pydantic – Data validation

⚙️ Workflow
Select a target job role.
Generate an AI-based interview question or enter a custom question.
Submit your interview answer.
AI analyzes the answer and evaluates its performance.
A score is assigned based on the evaluation criteria.
If the score is below 7, personalized improvement feedback is generated.
A final evaluation report is created and made available for download.

🎯 Project Objective
To provide students with an AI-powered platform for evaluating technical interview responses, identifying knowledge gaps, and improving their confidence and performance in placement interviews.
